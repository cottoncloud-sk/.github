# CottonCloud

CottonCloud is a Slovak WordPress development and web design studio focused on maintainable custom themes, purpose-built plugins, measurable performance work and rollback-safe quality assurance.

## Engineering focus

- route-aware asset ownership and small, explicit frontend dependencies;
- custom WordPress themes and single-purpose modules;
- performance measurement connected to guarded recommendations, tests and rollback;
- mobile-first UX, accessibility, technical SEO and operational monitoring;
- anonymized technical evidence with clear claim limits.

## Public engineering work

- [Route-Aware WordPress Assets](https://github.com/cottoncloud-sk/wordpress-route-aware-assets) — a conditional enqueue/dequeue pattern with an executable PHP contract.
- [CottonCloud Engineering Notes](https://cottoncloud-engineering.hashnode.dev/) — technical articles and anonymized implementation studies.
